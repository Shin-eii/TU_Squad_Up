## Project in one sentence

TU Squad Up helps verified Thammasat members create, discover, join, pay for, and complete campus activities.

## Core system

```text
React frontend → Express REST API → MySQL database
```

The central database table is `activities`. The `participations` table connects members and guests to activities.
